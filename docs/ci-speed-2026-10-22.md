## First implementation: repeated Tier 2 setup

Across 59 successful concrete test jobs, checkout took median 10 seconds
(range 8–12), bootstrap installation 15 seconds (9–87) and the full package
installation 34 seconds (28–49). Samples include PR, queue and master work;
this is not a controlled runtime estimate.

Test-only runners unpack a tree whose configure, source compilation and
symbol comparison already passed in the build job. They do not need full
Git history or browser/websocket source downloads. Use a normal shallow
checkout there; retain recursive submodules and full history in the builder.
The harness initializes those submodules only when building. Complete OFF/ON
CTest registries and all runtime package inputs remain unchanged.

Both fresh containers already refresh apt indexes before installing Git.
Reuse those same indexes in their later package install instead of refreshing
them a second time. Package caching, install retries and fail-on-error remain.

### Expected gains recorded before rollout

| Change | Measured opportunity | Expected gate saving / uncertainty |
| --- | --- | --- |
| Shallow test checkout without submodules | 10 s median total checkout per test job | 0–10 s per test runner; checkout overhead remains and overlaps between OFF/ON must not be added |
| Reuse the bootstrap apt index | Part of 34 s median package-install step | Unquantified until step-level runtime comparison; no package install is removed |
| Complete first change | Both test jobs wait for the same build/Fast Gate, then run independently | At most the longest affected path's reduction; no universal gate percentage promised |

Focused RED commit and GREEN results are recorded in the implementation PR.
Further runtime-package/image transfer, Rust rebuild/link, scheduling and
CTest experiments remain required by #1694; these first small setup changes
do not complete the batch. Conditional release/dev dependency cooking stays
unchanged: the existing post-job archive experiment in #1317 supports that
policy and requires a fresh controlled comparison before replacement.
